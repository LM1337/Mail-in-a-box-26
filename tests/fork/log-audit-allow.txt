# Allowlist of tests/fork/log-audit.sh: message classes that a clean box logs.
# One Python regex per line (searched in the class as the report prints it),
# then " # " and the reason. Keep the regexes narrow (anchor them, name the
# program); mark artefacts of the test network with "test network" and those
# of tests/fork/smoke.py with "smoke test" (rules that would also accept a
# real attack on a production box, such as failed logins to the control
# panel, go into log-audit-allow-smoke.txt instead). A rule that starts with
# "^\[in-place:PHASE\]" only accepts what the box logged in that phase of
# tools/upgrade-in-place-to-2604.sh (the old releases and the release
# upgrades, before setup), and one that starts with "^\[setup\]" only what
# it logged during a run of setup/start.sh (between its marks in the
# journal); the other rules apply in every phase. Started from
# what the rc6 test runs logged (fresh install, update from rc3, migration
# from v74 on 22.04, in-place upgrades from 22.04 and 24.04), each class
# checked.
