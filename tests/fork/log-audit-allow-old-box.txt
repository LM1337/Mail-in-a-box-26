# Additions for a log audit of the OLD box after tools/migrate-to-2604.sh has
# stopped it (phase stop-old: the services are masked in /run and stopped),
# and of a box upgraded in place for the minutes between the start of
# tools/upgrade-in-place-to-2604.sh and its quiesce (the old release still
# runs). Use with --allow-extra, with --since the start of the migration or
# the upgrade. Same format as log-audit-allow.txt. Started from what a v74 box
# on Ubuntu 22.04 logged; all of it came within seconds of stop-old.
^systemd: [A-Za-z0-9N.@_-]+\.(service|socket): (Current command vanished from the unit file, execution of the command list won't be resumed\.|Got notification message from PID N, but reception is disabled\.)$ # stop-old masks the running services in /run before it stops them
^systemd: apt-daily(-upgrade)?\.timer: (Unit to trigger vanished\.|Failed with result 'resources'\.)$ # stop-old masks the timers and their services; the timers stay "failed" until the next reboot of the old box or --rollback
^systemd: unit apt-daily(-upgrade)?\.timer is failed$ # see the line above
^postgrey: Couldn't unlink "/var/run/postgrey\.pid" \[Permission denied\]$ # postgrey of 22.04/24.04 (runs as user postgrey) at the stop
^\[WARNING\] Missing configuration options for contact admin; skipping$ # v74 and older: munin.conf has a contact without a command (upstream, B80 in the fork); munin-limits logs it every 5 minutes until the old box is stopped (migration) or quiesced (in-place upgrade)
^spamd: spamd: restarting using '[^']*/usr/sbin/spamd [^']*'$ # SpamAssassin's daily rule update on 24.04 (spamassassin-maintenance.service) reloads spamd; the old box until quiesce (the fork's rule for the quiesce phase covers the masked spampd)
^log: Warning: Shutting down logging for '(lmtp|auth-worker): ' with N clients$ # Dovecot 2.3: stop-old stops Dovecot while the LMTP processes of a delivery shortly before, or the auth workers of the last logins, still hold their log connection
^auth-worker: Warning: Killed with signal N \(by pid=N uid=N code=kill\)$ # Dovecot 2.3: stop-old stops Dovecot, and systemd ends the auth-worker processes that are still running
^postfix/lmtp: <hex>: to=<root@<hostname>>, (orig_to=<root>, )?relay=<ip>\[<ip>\]:N, delay=N\.N, delays=[N./]+, dsn=N\.N\.N, status=bounced \(host <ip>\[<ip>\] said: N N\.N\.N <root@<hostname>> User doesn't exist: root@<hostname> \(in reply to RCPT TO command\)\)?$ # old box (upstream v74): the output of a cron job (Ubuntu's cron.daily) goes to root@ of the box, which has no alias there (the fork's setup writes one, B82); the bounce goes nowhere
